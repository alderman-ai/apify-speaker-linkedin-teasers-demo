# Mid-Project Snapshots/Processed/

The seven archived speaker folders behind the PNGs in
`../Generated Images/`: `intake.md`, the folder `README.md`, and the
assets each run used — the stress test's five real Czech public figures,
plus the two early synthetic personas, `jana-novakova/` and
`petr-svoboda/`, made before the pipeline was finished.

They are mid-project snapshots, left exactly as they ran — the intakes
name the old pre-reorganisation paths, so never take a current path from
one. `petr-svoboda/` retains only `README.md` and `intake.md`; its images
were not kept. The five stress-test folders use real names and
likenesses, for an internal test only.
