# Getting Started/

The entrance for a complete beginner. One file, `getting-started.md`,
written for a person who has never used GitHub, a terminal, or an AI coding
tool: download the ZIP from GitHub, install an assistant (Claude Code, or
Cursor / VS Code + Copilot), open the folder, and paste one sentence —
*"Walk me through making my first speaker card"* — which routes to
`_internal/skills/novice-walkthrough.md`, the guided one-session wrapper
around `new-speaker` and `apify-speaker-card`. Send anyone here who sounds
new, unsure where to start, or says they have never done this before;
send anyone who already knows the two operator phrases to the root
`README.md` instead. Nothing in this folder is addressed to assistants or
read at run time, and `getting-started.md` deliberately points at no
assistant-facing file — if you rewrite it, keep it that way.

| file | what |
|---|---|
| `getting-started.md` | the six-step human entrance: get the folder, get an assistant, open it, paste the sentence, what to expect, what to do if it stops — plus a "have handy" checklist |
